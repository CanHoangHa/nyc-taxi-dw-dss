# Data directory

No dataset has been downloaded during the planning stage.

- `sample/` will contain only small samples suitable for Git and the university
  submission.
- `reference/` will contain small reference datasets such as the NYC Taxi Zone
  Lookup.
- Full monthly NYC TLC Yellow Taxi Parquet files will later be downloaded
  separately into a Git-ignored local raw-data directory.

Full raw trip data must not be committed to Git. Download instructions and the
exact source files will be documented when ingestion implementation begins.
